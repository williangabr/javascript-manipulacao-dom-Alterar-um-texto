# Manipulação do DOM com JavaScript

Este é um projeto desenvolvido durante meus estudos de JavaScript, com o objetivo de praticar a manipulação do DOM (Document Object Model).

## Sobre o projeto

A aplicação permite alterar o conteúdo de um título HTML através de um botão, utilizando JavaScript e o evento `click`.

## Tecnologias utilizadas

- HTML5
- JavaScript

## Conceitos praticados

- `document.getElementById()`
- `addEventListener()`
- `innerText`
- Funções em JavaScript
- Manipulação do DOM

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
4. Clique no botão para alterar o texto.

## Objetivo

Praticar os fundamentos do JavaScript e desenvolver minha lógica de programação através de pequenos projetos práticos.
